# 一次性敏感 HTTPS 客户端审计

状态：**端点无关实现与合成门禁；未启用，禁止用于真实账号**。

## 当前结论

`ephemeral_http.lua` 为未来扫码子任务提供最小 HTTPS 请求边界。它复用 [`verified_tls.lua`](TLS_SECURITY_AUDIT.md) 的 KOReader CA 链与 SAN 主机名校验，但没有真实接口地址、轮询、二维码、书架解析、退出调用或主界面入口。当前代码不会自行发起请求。

它只解决“受信任子进程怎样向预先审计的固定操作发送一次受限请求”。它不证明番茄当前扫码协议、授权主体、Cookie 语义或退出流程安全。

## 已实现的门禁

- 主机硬编码为 `fanqienovel.com`，调用方不能传入主机、URL、端口或代理。
- 构造客户端时必须提供代码内操作名到精确路径和 GET/POST 方法的白名单；路径不能包含查询串、片段、绝对 URL、双斜杠或 `..`。
- 调用时只接受 `body`、`cookie` 和 `headers` 三类参数；未知操作、动态 URL 参数和未列出的请求头在联网前拒绝。
- Cookie 最大 16 KB，只在该次请求头内存在；没有 Cookie jar、文件、设置、缓存或后台刷新。
- POST 正文最大 64 KB，响应最大 256 KB；响应 `Content-Length` 不一致时拒绝。
- 禁止 LuaSocket 全局 HTTP 代理和所有重定向。
- 只有策略明确列出的响应头会返回子任务；其他账号相关响应头不暴露。
- 超时、证书、重定向、限流、服务异常和底层异常只返回固定中文分类，不拼接原始异常、状态文本、响应正文或凭证。
- 模块不导入 logger，不调用 `print()`、`io` 或 `os`，不写文件或进程输出。

策略在构造时会复制，之后修改调用方原表不会改变已授权路径。当前没有生产策略，测试只使用 `/__synthetic__/...` 虚构路径，不连接网络。

## 敏感成功结果

请求成功后，正文和策略允许的 `Set-Cookie` 等响应头仍可能包含凭证或账号数据。它们只允许留在同一个可取消子进程中，用于完成下一次固定操作或转换成最小书架字段。调用方必须：

1. 不记录、不显示、不持久化原始成功结果；
2. 不把原始正文、Cookie 或响应表直接返回给 `ephemeral_task.lua`；
3. 在子进程内严格解析并只返回已经验证的最小书架 JSON；
4. 完成或失败后删除所有可达凭证引用；
5. 接受 Lua 字符串无法原地可靠清零，以及 `SIGKILL` 时无法执行 Lua 清理的限制。

本模块自身不保存 Cookie，因此也不声称已经正确实现多条 `Set-Cookie`、`Expires`、`Domain`、`Path`、`Secure`、过期删除或同名覆盖语义。真实协议需要哪些 Cookie 行为，必须先用无敏感内容的测试账号重新审计，不能猜测。

## 合成证据

`tests/test_ephemeral_http.lua` 使用凭证 canary 覆盖：

- 策略为空、绝对 URL、查询串和路径穿越拒绝；
- 策略复制后不可由外部修改；
- CA/SAN 连接器复用、固定主机/路径/方法、POST 正文和允许凭证头；
- 未知操作、动态 URL、未列出头、CRLF 注入、GET 正文和代理在联网前拒绝；
- 原始异常、证书失败、超限响应和重定向不回显 canary；
- 未列出的响应头不暴露；
- 任何已尝试请求都会复位 KOReader 网络超时。

这些测试不发真实请求，也不能证明真实成功响应不会在未来的端点任务代码中被误传到日志或匿名管道。

## 继续 No-Go

- 未现场确认官方扫码域名、精确路径、方法、参数、授权主体和二维码有效期；
- 当前硬编码主机不能覆盖未经审计的其他官方域名，禁止为了“先跑通”而放宽为后缀或任意 HTTPS；
- 未实现和验证真实 Cookie 合并、过期、轮询间隔、最大次数及退出语义；
- 未实现把成功响应严格转换为最小书架 JSON 的单一子任务；
- 未扫描真实 KOReader 日志、崩溃输出、设置、缓存和用户分区文件变化；
- 未在 PW3 验证取消、超时、网络切换、系统时间错误和强制退出。

以上条件完成前，该模块只能作为安全边界原型，不能接入“扫码导入”按钮或用于真实账号。
