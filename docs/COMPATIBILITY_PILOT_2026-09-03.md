# 公开兼容性先导审计（2026-09-03）

本文件只记录正式 30 本/90 场景矩阵开始前的一次采集路径验证。它不是发布候选证据，不计入 `--require-complete` 门禁，也不能替代 Kindle 缓存落盘和界面检查。

## 边界

- 来源仅为番茄小说官网的[公开排行榜](https://fanqienovel.com/rank)、一本公开书籍页、对应官方目录接口及该书前/中/末三个章节页。
- 请求串行执行，章节请求间隔超过 2 秒；未登录、未携带 Cookie、未使用代理、未跟随重定向。
- 单响应限制为 1 MB、总超时 20 秒；遇到 HTTP 429、`Bdturing-Verify` 或 `X-Vc-Bdturing-Parameters` 会立即停止。
- 原始 HTML、JSON、响应头、书名、作者、章节标题和正文只存在于采集进程内存，没有写入仓库、临时文件或标准输出。
- 输出仅保留公开数字 ID、字数统计、解析分类和只基于字段名及值类型的 SHA-256 结构指纹。

## 环境与方法

- 插件提交：`379bbfe040d477cdabc5413107abe7e164b2f49d`
- 桌面环境：macOS + Node.js `fetch` + LuaJIT
- 网页 JSON：Node.js `JSON.parse()`；本机没有 KOReader 的 `rapidjson`，因此本次不验证 `Parser.decode_json()` 的运行时一致性。
- 书籍、目录和章节字段经全字节十进制转义的内存管道交给真实 `fanqielite/parser.lua`，分别调用 `book_from_state()`、`directory_from_payload()` 和 `chapter_from_state()`。
- 没有调用 `Storage.write()`，所以不能把公开正文场景标记为 `cache_saved=true`。
