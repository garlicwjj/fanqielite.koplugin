# 稳定版候选质量计划

本文记录从 0.1.0 实验原型走向稳定版候选所需的证据。它不是发布日期承诺；所有项目全部通过后仍需项目所有者明确确认，才能决定是否发布正式版。

## 当前架构审计

| 模块 | 当前职责 | 已有保护 | 主要缺口 |
| --- | --- | --- | --- |
| `main.lua` | KOReader 菜单、网络任务和阅读入口 | 操作反馈、删除确认、独立书籍状态、可取消子进程 | 需要实机验证取消、重复点击、Wi-Fi 切换和强制退出 |
| `http.lua` | 官方 HTTPS GET | 官方域名白名单、禁用重定向、1 MB、20 秒、长度检查、中文错误 | DNS 解析不受总超时完全控制；尚未覆盖网络切换和 TLS 设备差异 |
| `parser.lua` | 书籍、目录、章节和 XHTML | ID 校验、短预览/锁定/未知 PUA 安全拒绝 | 兼容矩阵自动门禁已建立，但 30 本/90 场景真实证据尚未采集 |
| `library.lua` | 多书书架、迁移和进度 | 版本化迁移、去重、边界修正、降级字段 | 需验证设置写入中断、升级/降级和多次强制退出 |
| `storage.lua` | 章节缓存 | 临时文件后原子改名、每书 12 章、损坏缓存拒绝、严格删除白名单 | 需实机验证只读磁盘、空间不足和部分清理失败的用户提示 |
| `import.lua` | JSON 文件导入 | 256 KB、500 本、字段白名单、凭证拒绝、全量验证后确认 | Kindle 文件选择与导入已单机实测；仍需用测试账号验证浏览器导出 |
| `tools/export-bookshelf.js` | 浏览器最小书架导出 | 不读取 Cookie、只输出白名单、大小限制 | 仍是原型；需要测试账号验证官方动态接口和下载流程 |

## 优先级

### P0：合并任何功能前必须完成

1. 在备份现有设置后，用 Kindle 验证 0.1.0 单书数据迁移、多书切换、离线缓存、移除和清缓存。
2. 验证网络失败不会卡死 KOReader：断网、慢响应、TLS/时间错误、响应过大和重定向。
3. 为损坏缓存、设置写入失败和磁盘空间不足增加可复现测试与安全提示。
4. 在实机验证基于 KOReader 2026.03 `Trapper:dismissableRunInSubprocess()` 的可取消网络任务：点按取消、重复点击、Wi-Fi 切换和强制退出。
5. 任何堆叠 PR 只有在可靠的“遇错即停”CI 下重新通过，才算有效证据。

### P1：默认本地书架达到日常可用

1. 建立 30 本书、至少 90 个章节场景的兼容矩阵，规则见 `compatibility-matrix.md`。
2. 为书籍页、目录和章节状态的已知结构变体建立去正文的最小夹具。
3. 加入缓存损坏检测、目录更新时间和更清楚的离线状态。
4. 完成 JSON 浏览器导出测试账号验证与新手文档。
5. 搜索保持暂缓：2026-08-16 官方搜索接口直连返回空正文，公开搜索页触发滑块验证。不得绕过验证码，也不得用第三方搜索替代；只有找到可在 Kindle 上合法稳定使用的官方路径后再实现。

### P2：可选账号导入

1. 先完成独立威胁模型，列出 Cookie 生命周期、内存清理、日志脱敏、取消/超时、退出接口和强制退出场景。
2. 仅用无敏感内容的测试账号验证一次性二维码。
3. 自动检查设置、缓存、日志和崩溃输出中不存在 Cookie、session、CSRF、Token 或请求头。
4. 扫码成功、失败、取消、过期和退出失败均不得影响本地书架。
5. 未通过安全审计前始终标记为实验性，且不实现长期登录或后台同步。

## 发布候选门禁

- 30 本/90 场景矩阵完成；公开且允许读取的样本正确解析率至少 95%。
- 所有未知 PUA、登录墙、付费锁定、章节 ID 不一致和畸形响应安全拒绝。
- Lua 5.1、浏览器工具和导入安全测试全部通过，CI 不会掩盖中间失败。
- 至少完成一次升级、重启、降级和卸载回退实机演练，并记录设置与缓存变化。
- 安装文档由未接触项目的新手按步骤验证，5 分钟内能从已安装 KOReader 到开始阅读。
- 生成候选包、测试证据和评估报告；不自动合并、打 `1.0` 标签、创建正式 Release 或宣传。

## 当前证据状态

- 0.1.0 已在 PW3 5.16.2.1.1 + KOReader 2026.03 验证单书、88 章目录和公开正文阅读。
- 开发栈已在同一台 PW3 验证 0.1.0 单书迁移、多书共存与切换、旧章节缓存和 KOReader sidecar 保留，以及测试书移除后通过 JSON 恢复；降级和强制退出仍未实机覆盖。
- 飞行模式下本地书架、两本书切换及两本已缓存章节均正常；测试书恢复约 75% 本机位置，原书也保留自身位置。清理测试书缓存精确删除 1 个 XHTML，保留 `.sdr`、28/87 章目录和另一本文档缓存；离线缺缓存时请求联网且取消安全，联网重建后仍恢复约 75%，全程没有乱码、报错或闪退。
- 网络边界、可取消子进程、损坏缓存和部分清理失败已有自动测试与 CI，网络失败和取消路径仍未在 PW3 完成矩阵验证。
- 严格 JSON 已在 PW3 完成文件选择、确认、导入、28 章目录加载、阅读位置一次性恢复和 2 本书本地导出；导出文件通过插件严格导入器复验且无凭证、正文、缓存或临时残留，浏览器导出仍未使用测试账号验证。
- 草稿 PR #19 已记录文件选择确认框修复：首次约 60% 导入位置应用后，本机约 75% 位置在重新打开时优先恢复；最新 CI 通过。
- 兼容证据工具已能强制检查 30 本/90 场景、五档书长、12/18 完结状态、每本前中末、单一候选提交、95% 公开解析率及六类安全拒绝覆盖；真实矩阵仍未开始，不能据此声称兼容率达标。
- 30 本/90 章节兼容矩阵、一次性扫码导入安全审计、新手 5 分钟安装测试和发布候选评估报告均未完成。
- 稳定版候选条件仍未满足。
