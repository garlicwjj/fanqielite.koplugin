# Fanqie Lite for KOReader

[![Lua 5.1 checks](https://github.com/garlicwjj/fanqielite.koplugin/actions/workflows/lua51.yml/badge.svg)](https://github.com/garlicwjj/fanqielite.koplugin/actions/workflows/lua51.yml)

一个面向 KOReader 的番茄小说实验性插件。第一版只使用番茄小说官方网页，读取网页明确公开展示的章节。

## 0.1.0 范围

- 输入官方书籍链接或书籍 ID。
- 开发分支可按书名或作者名查询番茄官网当前公开搜索接口，并从前 10 条结果加入书架；若官网要求浏览器滑块验证，会安全失败并提示改用官网链接。
- 获取官方书籍信息和目录。
- 获取公开章节网页，解码当前已知的 PUA 字符混淆。
- 生成本地 XHTML，交给 KOReader 原生阅读引擎。
- 通过插件菜单打开目录、上一章和下一章。
- 每本书最多保留 12 个章节缓存；写入新章节后会优先清理较早写入的缓存。

第一版不登录、不读取个人书架、不上传进度、不使用第三方书源、不批量下载全本，也不会绕过登录、付费或章节锁定。

## 安装

候选测试包解压后应直接得到 `fanqielite.koplugin` 目录。将它复制到 KOReader 的 `plugins` 目录，完整重启 KOReader，然后从工具菜单打开“番茄小说（实验版）”。分步操作、目录检查、升级备份、常见错误和安全回退见 [`INSTALL.md`](INSTALL.md)。不要把 GitHub 源码压缩包的外层目录直接复制到 Kindle。

## 已知限制

- 番茄网页和字符映射可能随时变化。遇到未知 PUA 字符时插件会拒绝缓存，避免显示乱码。
- 部分章节只向未登录网页返回短预览，第一版会提示不可公开读取。
- 0.1.0 的同步请求有 20 秒总超时，但可能短暂阻塞 KOReader；开发分支已改用 KOReader 官方可取消子进程，尚待实机验证后合并。
- 开发分支会使用 KOReader 自带 CA 集明确验证番茄官方 HTTPS 的证书链和 SAN 主机名；Kindle 系统日期错误时会安全失败，先让设备联网校时后再重试。固定源码与安装包证据、实现边界见 [`docs/TLS_SECURITY_AUDIT.md`](docs/TLS_SECURITY_AUDIT.md)。
- 第一版仅为个人研究和互操作性验证，请尊重平台规则与作品版权。

## 验证状态

- 已按 KOReader 2026.03 的本地代码核对插件接口，并通过 Lua 5.1 语法和核心解析测试。
- 2026-08-13 已用番茄官方书籍页、目录接口、公开章节页和登录墙页面完成只读烟雾测试。
- 2026-08-16 已在 Kindle Paperwhite 3（固件 5.16.2.1.1、KOReader 2026.03）完成首次实机验证：插件正常加载，书籍信息与 88 章目录正常显示，公开章节正文完整、无乱码且翻页正常。
- 2026-08-17 至 19 日在同一台 PW3 验证开发栈：旧单书数据迁移后保留 87 条实际目录记录、章节缓存和 KOReader 阅读位置；严格 JSON 文件导入新增测试书且不覆盖原书；测试书获取 28 章后首次恢复约 60% 导入位置，改为约 75% 后重新打开仍以本机位置为准。
- 2026-08-19 在飞行模式下验证本地书架仍显示两本书，多书切换正常；两本已缓存的第 1 章均可直接打开，不提示联网，正文与各自 KOReader 阅读位置正常。清理测试书缓存只删除对应 XHTML，保留 28 章目录与 `.sdr`；离线重开会请求联网且可安全取消，联网重建缓存后仍恢复约 75%。
- 2026-08-19 移除测试书后原书仍为 87 章，两本缓存和 `.sdr` 均未改变；用已验证 JSON 恢复测试书、联网恢复 28 章目录后，飞行模式下直接复用原 XHTML 并恢复约 75% 本机位置。
- 目前只验证过上述一台设备；番茄网页仍可能变化，因此 0.1.0 继续标记为实验版。

## 数据位置

- 设置：`koreader/settings/fanqielite.lua`
- 上一版设置备份：`koreader/settings/fanqielite.lua.old`（开发分支）
- 章节缓存：`koreader/fanqielite/<book-id>/`

删除插件不会自动删除缓存；如需清理，可在退出 KOReader 后删除上述 `fanqielite` 数据目录。

## 下一版开发中

当前开发栈已实现多书本地书架，包括独立阅读进度、目录刷新、排序、移除书籍和按书清理缓存。移除书籍与删除缓存始终独立确认：移除成功后可选择立即清理，取消则保留缓存供重新添加同一本书时复用；`.sdr` 阅读位置和未知文件不在删除白名单内。书籍页会显示本地目录章数、缓存文件数和可靠的目录刷新时间，并明确说明离线只能打开完整缓存；旧数据不会伪造刷新时间。旧版单书设置会自动迁移，并继续同步兼容字段以便降级；迁移、多书切换、导入位置的一次性恢复、按书清缓存和移除后恢复已在一台 PW3 验证，新的移除后清理选择、本地状态提示及降级回退仍待实机覆盖。

扫码导入目前仍只显示清晰的“开发中”说明，尚未接触或保存任何账号凭证。真实接口实现前必须满足独立的 [`docs/QR_THREAT_MODEL.md`](docs/QR_THREAT_MODEL.md)，其中列出了生命周期、退出失败、强制退出、日志脱敏和当前 No-Go 条件。开发分支已有未接端点、未接界面的敏感 HTTPS 客户端门禁，证据与剩余风险见 [`docs/EPHEMERAL_HTTP_AUDIT.md`](docs/EPHEMERAL_HTTP_AUDIT.md)；临时会话只复制固定、受限的内存凭证袋，最小书架结果还必须经过 [`docs/SUBPROCESS_SECURITY_AUDIT.md`](docs/SUBPROCESS_SECURITY_AUDIT.md) 记录的双向验证才能越过匿名管道。这些都不是可用的登录功能。严格本地 JSON 书架导入格式见 [`docs/bookshelf-format.md`](docs/bookshelf-format.md)；Kindle 文件选择、确认、导入、首次阅读位置恢复和本地书架导出已完成单机实测，浏览器端导出工具仍需使用无敏感内容的测试账号验证。插件也可将本地书架安全导出到 Kindle 用户盘根目录，供备份或迁移，不包含账号凭证、正文或章节缓存。

“设置与数据”集中提供书架导入/导出、缓存边界、隐私说明和完整卸载路径。插件不会自动执行卸载或删除用户文件。本地导出已在一台 PW3 验证，但仍不能替代跨设备测试、浏览器导出验证或其他发布候选门禁。

未经实机验证、安全审计和项目所有者明确确认，本项目不会标记为稳定版 1.0。

稳定版候选的优先级、风险和证据门禁见 [`docs/QUALITY_PLAN.md`](docs/QUALITY_PLAN.md)，30 本/90 章节兼容测试方法见 [`docs/compatibility-matrix.md`](docs/compatibility-matrix.md)。
